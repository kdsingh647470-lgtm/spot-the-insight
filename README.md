- React + TypeScript

- Tailwind CSS

- Supabase backend

- Responsive PWA

- Google Material Design

- Dark and Light mode

Game Features

The player is shown two images side by side.

Each level contains 5 hidden differences.

Player taps the differences.

Correct tap:

- Green animation

- Circle appears

- Score +100

Wrong tap:

- Shake animation

- Lose one life

Player has:

- 3 lives

- Hint button

- Timer

- Pause button
